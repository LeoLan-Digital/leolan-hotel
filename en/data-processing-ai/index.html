Public pre-contract information, updated 15 September 2026. It is not a signed agreement and does not replace the versioned documents supplied before contract formation.

Current data path

Operational NOVA application and contract data at rest are primarily stored in a local server and PostgreSQL environment operated by LeoLan. Media may additionally reside on locally connected network storage operated by LeoLan.

External processing

Activated communication, email, security, payment, PMS and AI functions may transmit the data required for them to documented external providers. The current demo chat may in particular use external AI processing. Local primary storage therefore does not mean that every processing step is local.

Planned dedicated AI server

A Mac Studio or dedicated local AI server is planned as the future standard route for suitable AI functions. It becomes production-ready only after installation, security review, documented acceptance and approval.

95% target

After that approval, the target is to run at least 95% of eligible AI processing cases fully locally per customer and calendar month. Numerator, denominator, exceptions and evidence must be defined in the relevant contract. Before definition and measurement, 95% is neither a current rate nor a guarantee.

Customer information

Before production use, the customer receives the concrete configuration, data categories, purposes, external providers and safeguards. Functions with a different data path are identified.
